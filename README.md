# Зомби-долина

Браузерная игра от первого лица: рыцарь с огромным мечом против орд зомби. Играть: https://sssanek.github.io/zombie-valley/

Управление: WASD, мышь, ЛКМ, Shift, Пробел, 1–4 / колесо, Esc.

Принцесса — фрагмент картины Эдмунда Блэра Лейтона «Посвящение в рыцари» (1901, общественное достояние).
